
# Student Information Formatter

## Version 1 – Basic Input and Output

### Description
This Python program asks the user to enter their basic student information and displays it in an organized format.

### Information Collected
- Name
- Age
- Grade Level
- Section

### How to Run
1. Open the Python file in VS Code.
2. Run the program.
3. Enter the requested student information.
4. View the formatted student information.

### Programming Concepts Used
- Variables
- input()
- print()
- Basic output formatting

### File Name
student_information_v1.py
